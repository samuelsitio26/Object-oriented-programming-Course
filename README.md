# 🎓 Object-Oriented Programming Course — Del Institute of Technology

## `Overview 💡`
_Pemrograman Berbasis Objek_ (`PBO`) adalah mata kuliah lanjutan dari `Pemrograman Prosedural (PEMPROS)` yang diajarkan di Program Studi Sistem Informasi, Institut Teknologi Del. Mata kuliah ini fokus pada prinsip-prinsip dasar dan lanjutan dalam pemrograman berbasis objek (*Object-Oriented Programming*) menggunakan bahasa pemrograman `Java`.  

Mahasiswa akan mempelajari konsep seperti:
- Enkapsulasi, Inheritance, Polymorphism
- Abstraksi, Interface, dan Generics
- Manajemen koleksi dan file
- Penerapan desain program modular dan reusable
