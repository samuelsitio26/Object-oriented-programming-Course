# 🎓 Object-Oriented Programming Course — Del Institute of Technology

## `Overview 💡`

*Pemrograman Berbasis Objek* (PBO) adalah mata kuliah lanjutan dari **Pemrograman Prosedural (PEMPROS)** yang diajarkan di Program Studi **Sistem Informasi**, Institut Teknologi Del.

Mata kuliah ini mengajarkan paradigma *Object-Oriented Programming* menggunakan bahasa pemrograman `Java`, mencakup topik:

* Enkapsulasi, Inheritance, Polymorphism
* Abstraksi, Interface, dan Generic Class
* Koleksi data dan manajemen file
* Perancangan program modular dan reusable
